# Affiliate Marketing Studio + Ollama / OpenRouter

## New Capabilities

### LLM Providers
- **Ollama** – fully local, no key required (default `http://127.0.0.1:11434`)
- **OpenRouter** – one API key → hundreds of models (GPT-4o, Claude, Llama, Gemini, etc.)

### Affiliate Studio
1. **Product Research** – AI expands any product into benefits, pain points, audience, USPs
2. **Script Generator** – high-converting short-form / UGC / review / story scripts for TikTok, YouTube, Instagram, Facebook
3. **Ad Creatives** – multiple angle headlines + primary text + visual suggestions
4. Campaign storage so you can build a full pipeline

## How to use

1. **AI Settings** → add:
   - OpenRouter API key (recommended for quality)
   - or Ollama base URL if running locally

2. Open **AI Tools** → **Affiliate Studio**

3. Enter product name → Research → Generate Script

4. Copy the script → feed it into **AI Video** or **AI Audio** to produce the actual content

## Full pipeline example

1. Research product with Affiliate Studio
2. Generate TikTok short-form script
3. Send script to AI Audio (ElevenLabs TTS)
4. Generate B-roll / product video with AI Video (Kling)
5. Drop both into the timeline + add captions
6. Export vertical video ready to post
